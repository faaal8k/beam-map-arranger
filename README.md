# مرتّب خريطة بيام

أداة ويب لترتيب خرائط BeamNG داخل المتصفح، مع عرض ثلاثي الأبعاد (والعرض من فوق كخيار). تفتح ملف الخريطة من جهازك، تحرّك المجسمات وتكبّرها وتدوّرها باللمس، ثم تصدّر الملف المحدّث. لا يُرفع شيء إلى أي سيرفر.

افتح التطبيق من هنا: https://faaal8k.github.io/beam-map-arranger/

- لمسة واحدة للتحديد، وسحب القطعة المحددة على التضاريس
- قرص بإصبعين على المحدد للتكبير، ولف للدوران، ومقابض على الإطار لتغيير الحجم
- ضغطة مطوّلة: قائمة فيها تكرار وحذف ولصق بالأرض ونسخ/لصق الإعدادات
- ضغطة بإصبعين للتراجع، وثلاث أصابع للإعادة

three.js (MIT) و JSZip (MIT/GPLv3) مضمّنان محلياً، والتطبيق يشتغل بدون نت بعد التحميل.
